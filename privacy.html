隐私说明

简单地说：你的学习记录只保存在你自己的浏览器里，本站没有账号系统，也不会把记录上传到任何服务器。

最后更新：2026年11月13日

我们保存了什么

  • 你输入的学习内容和复习完成记录，保存在浏览器的本地存储（localStorage）里，只存在你的设备上。
  • 你建的坚持项（名字、ON/OFF 状态）和每天的打卡记录，同样保存在浏览器的本地存储里。
  • 你的设置（界面颜色选的是日间、夜间还是跟随系统；建了几个科目框、每个框叫什么名字），同样保存在浏览器的本地存储里。
  • “今天的摘要已经看过了”这个标记，保存在浏览器的会话存储（sessionStorage）里，关掉标签页就会清除。
  • 本站不需要注册或登录，不收集姓名、邮箱、手机号等个人信息。
  • 本站的代码不会把这些记录发送出去，我们也无法查看你的记录。
  • 本站没有使用统计分析、广告或追踪脚本，也没有设置 cookie。

备份文件

  • 导出备份是在你的浏览器里把记录生成一个文件，直接下载到你的设备上，不经过任何服务器。这个文件里是你写下的全部学习内容、完成记录、坚持项和打卡记录、科目框设置，没有加密，请自己保管好。
  • 导入备份时，文件只在你的浏览器里被读取，同样不会上传。

用到的第三方服务

网站字体使用你设备上自带的字体（如微软雅黑、楷体），不会从其他网站下载字体。唯一的第三方是网站托管方：

GitHub Pages（网站托管）

本站托管在 GitHub Pages。作为托管方，GitHub 可能会按其隐私声明记录访问日志（例如 IP 地址）。

如何查看或删除你的数据

  • 查看全部数据：在应用里点“备份”，导出的文件里就是本站保存的全部记录。
  • 删除单条学习内容：在应用里点那一条右边的叉。
  • 删除全部数据：在浏览器设置里清除本站（sleepgenius07.github.io）的网站数据。清除后，没有备份文件就无法恢复。
  • 因为数据只在你的设备上，换设备或清除浏览器数据后记录会丢失，除非事先导出了备份。

变更与联系

如果以后功能变化影响到数据的处理方式，会先更新这一页。有疑问可以到 GitHub 项目页留言。
