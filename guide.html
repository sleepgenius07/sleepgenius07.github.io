使用指南

从添加第一条学习内容，到每天完成复习，一共四步。

一、添加学习内容

  1. 点击顶部的“开始复习”进入应用，日历里会默认选中今天。
  2. 想记录哪一天的内容，就点日历上的那一天（补记以前的内容也可以）。
  3. 在“记下今天学的”输入框里写下知识点，每行一个。输入框里的横线就是这个意思：一行一条。
  4. 点“添加到 X月X日”（电脑上也可以按 Ctrl + Enter）。添加成功后，下方会出现这一天的学习列表和它们的复习日。

在学习列表下面的“复习日”里点任意一个日期，日历会直接跳到那一天。

每条学习内容的右边有六个小圆点，代表它的六次复习：绿色是已经完成，黄色是今天该复习，红圈是过期了还没做，空心是还没到日子。

三、读懂日历上的圆点

  • 蓝色：这一天记了新内容
  • 黄色：这一天有待复习的内容
  • 绿色：这一天的复习全部完成
  • 红色：复习日期已过，但还没有完成（逾期）

日历上涂了荧光笔的数字是今天，蓝色的格子是你现在选中的那一天。

点日历上的某一天，右边（手机上是下方）会显示这一天要复习的内容，按“哪天学的”分组，并标出第几次复习。每组右侧的“保持率”只是一个示意值，墨迹越淡表示隔得越久、忘得越多，说明见关于页。

四、完成复习

  • 复习完一条，点一下这一行就打上勾；点错了再点一次就能取消。
  • 打开应用时，如果今天有复习或有逾期内容，会自动弹出“今日复习摘要”。点“开始复习”或右上角的叉关闭；想再看，随时点顶部的“今日摘要”。
  • 有内容过了复习日还没打勾时，顶部会出现红色的“逾期 N 项”。点开就是逾期清单，补上之后直接在清单里打勾。
  • 顶部的“连续 N 天”是连续坚持的天数：某一天的复习全部完成才算数，中断就会重新计算。
  • 日历下面的三个数字是累计：已学内容、学习天数、完成的复习次数。
  • 记错了？在学习列表里点那一条右边的叉就能删除，它的复习安排也会一起消失。删错了，马上点屏幕下方提示条里的“撤销”。

备份和换设备

你的记录只保存在当前设备的当前浏览器里。清除浏览器数据、使用无痕/隐私窗口、换手机或换浏览器，都会看到一个空白的日程。

  • 导出：点应用顶部的“备份”，再点“导出”，会下载一个名叫 ebbinghaus-backup-日期.json 的文件。建议隔一段时间导出一次。
  • 导入：在新设备上打开应用，点“备份”里的“选择文件”，选中那个备份文件。导入只会把记录加进来，不会删掉设备上已有的内容。

其他

  • 手机上想像 App 一样使用，可以在浏览器菜单里选择“添加到主屏幕”。
  • 手机或电脑开了深色模式时，网站会自动换成夜间配色。
